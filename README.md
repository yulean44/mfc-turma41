# Planeta de Estudos

Site de estudo com um planeta 3D low-poly que cresce conforme você estuda: sessões de foco, flashcards com registro de acertos e erros, seções de conteúdo, missões, conquistas e criaturas.

- Abre direto no navegador (GitHub Pages), sem instalação.
- O progresso fica salvo no navegador de quem usa.
- Primeira matéria: Medicina de Família e Comunidade (2ª Unidade, Turma 41).

Modelos 3D das criaturas: pacotes Quaternius (CC0). Biblioteca 3D: three.js.
